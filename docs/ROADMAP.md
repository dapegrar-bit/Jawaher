# خارطة الطريق التنفيذية لـ«جواهر ميزان»

| المرحلة | المجال | شرط القبول |
|---|---|---|
| 0.1 — المُسلّم هنا | مصادقة، منشأة، دليل حسابات، قيود مسودة وترحيل، ميزان مراجعة، سجل أحداث | اجتياز اختبارات الوحدة وSmoke على PostgreSQL في بيئة التطوير |
| 0.2 | تصحيح القيود والقيود العكسية، إنشاء سنة/فترة وإقفالها، ملخص الأرصدة | عدم تعديل القيود المرحلة وتطابق تقارير الإقفال |
| 0.3 | العملاء، الموردون، مسودات المبيعات والمشتريات | سيناريوهات حسابات دائنة ومدينة متوازنة |
| 0.4 | الفوترة الإلكترونية السعودية | التحقق من XML والتوقيع والشهادات وتدفقات ZATCA ذات الصلة مع مختص |
| 0.5 | جواهر جسر (موصل واحد) | قراءة بيانات مع تطبيق معدل الطلبات ومنع التكرار وإدارة موافقة العميل |
| 0.6 | التقارير، المطابقة البنكية والاستيراد | تسوية مراجعة على بيانات اختبارية وتفسير الفروق |
| 0.7 | أمن وتوسع وتشغيل | تدقيق خارجي، RLS، MFA، مراقبة ونسخ واستعادة |
| 1.0 | إطلاق تجاري مشروط بالتحقق القانوني والمحاسبي والأمني | اجتياز UAT والامتثال والعقود وسياسة الخصوصية |

**ملحوظة:** هذه مراحل نطاق وليست مواعيد مضمونة، وتقدير تكلفتها يحتاج إلى عروض فنية حسب الحجم والعدد والمخاطر.
