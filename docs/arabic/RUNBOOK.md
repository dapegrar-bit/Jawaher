# دليل التشغيل — خطوات مختصرة

1. تثبيت Docker وتخصيص 4GB RAM على الأقل لتجربة أولية محلية وفق حجم النظام.
2. نسخ `.env.example` إلى `.env` وضبط سر قاعدة بيانات آمن.
3. تنفيذ `docker compose up --build -d` من جذر المشروع.
4. انتظار نجاح `curl http://localhost:4000/health`.
5. فتح `http://localhost:3000` وتسجيل مستخدم جديد. ينشئ النظام منشأة وفترة السنة المالية الحالية ودليل حسابات تلقائيًا.
6. إضافة عميل ومورد من قسم جهات الاتصال، ثم فاتورة بيع مسودة وترحيلها وتسجيل تحصيل.
7. مراجعة ميزان المراجعة والتقارير والذمم وسجل التدقيق.
8. اختبار `node api/scripts/smoke.mjs` و`node api/scripts/commerce-smoke.mjs`.
9. عند تحديث البرنامج لا تنسي نسخ البيانات أولًا وعدم حذف Docker volumes.

## أعطال متوقعة
- `port already allocated`: خدمة أخرى تستخدم المنفذ 3000 أو 4000؛ غيري الربط في Compose.
- `password authentication failed`: راجعي تطابق `.env` مع قاعدة البيانات القديمة؛ تغيير كلمة مرور volume موجود لا يغير اعتماد PostgreSQL تلقائيًا.
- `relation business_documents does not exist`: ترقية قاعدة البيانات الثانية غير مطبقة على قاعدة قديمة.
- `Cannot find module`: يلزم تنزيل حزم npm بصورة سليمة في بيئة اتصال بالإنترنت.
- `CORS`: نطاق WEB_ORIGIN لا يطابق مصدر واجهة الويب.

**في الإنتاج:** لا تفتحي قاعدة PostgreSQL للإنترنت، واستخدمي HTTPS وشبكة خاصة وخدمات أسرار وإجراءات أمن معتمدة بعد مراجعة مستقلة.
