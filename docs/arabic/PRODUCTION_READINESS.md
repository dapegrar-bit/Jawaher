# متطلبات الخروج من النسخة التجريبية إلى السوق

القرار: **غير جاهز للإنتاج** حتى إغلاق البنود التالية وإثباتها بمحاضر اختبار.

## المحاسبة والضريبة
- تدقيق مستقل للقواعد المحاسبية وحالات المعالجة والخصومات والمرتجعات والإشعارات الدائنة والمدينة والدفعات المقدمة ومراكز التكلفة.
- معالجة السنوات والفترات المالية المتعددة وإقفالها وفتحها ضمن صلاحيات وإجراءات موثقة.
- اعتماد قائمة المركز المالي والأرباح والخسائر والتدفقات النقدية والإفصاحات وفق المعايير المطبقة على نوع المنشأة.
- دعم دقة العملات والتقريب الضريبي والاستثناءات وضوابط الضريبة المزدوجة.
- تكامل ZATCA Phase 2 وفق XML والتوقيع والتشفير والشهادات والربط وSDK وSandbox واستكمال جميع المتطلبات الفعلية.
- إدارة الأرشفة وفترات الاحتفاظ والتصدير وإجراءات المعالجة القانونية عند فشل الإرسال.

## الأمان والخصوصية
- MFA، وقواعد كلمات المرور/محاولات الدخول وقفل/تقييد المعدلات وإدارة جلسات صارمة.
- عزل المستأجرين بسياسات متعددة الطبقات، ومراجعة PostgreSQL RLS أو بديل مكافئ قابل للاختبار.
- مراجعة IAM والصلاحيات الدقيقة وتفويض العمليات الكبيرة ومبدأ الفصل بين المهام.
- حماية CSRF/CORS، ترويسات الأمان، التحقق من المحتوى، فحص المسارات، معالجة حقن البيانات.
- نقل الأسرار إلى Secret Manager وفصل أسرار المؤسسات والأجهزة والخدمات.
- تشفير النسخ الاحتياطية واختبار الاستعادة وRPO/RTO واتفاقيات SLA ومراقبة 24/7 حسب تعاقدات الخدمة.
- مراجعة PDPL واللوائح وشروط الاستضافة والمعالجة والنقل والاحتفاظ بالبيانات.
- اعتماد سياسة استجابة للحوادث وتسجيل الأحداث وتعريف نقاط إبلاغ العملاء.

## هندسة المنتج
- اختبارات بناء `npm install && npm run build` واختبارات تكامل PostgreSQL الفعلي ضمن CI.
- تشغيل اختبارات الضغط والمزامنة والتسابق وتكرار الدفع والترحيل، خاصة في عمليات القفل المتزامنة.
- اعتماد Migrations بدل SQL init-only، وترقيات من دون فقد أو ازدواج بيانات.
- تجهيز البيئة المرحلية وبيئة الإنتاج مستقلة مع HTTPS/DNS وWAF وحماية DDoS.
- اختبار واجهة التطبيق على Android/iOS/Safari والتصميم العربي والأرقام والتواريخ.
- سياسة إصدار ثابت للـ API، وشروط الاستضافة والفوترة والترخيص والدعم.

## السوق والتكامل
- تسجيل العلامة التجارية والاستيثاق من الاسم والنطاق.
- استكمال موافقات مزودي APIs التجاريين وتفعيل صلاحيات وحسابات كل منشأة على حدة.
- آليات متينة لانتقال البيانات وكشف المكرر ورجوع المزامنة وحقوق المستخدمين في بياناتهم.
- استكمال المستندات النظامية والعقود واتفاقيات المعالجة والفوترة والاشتراكات.
